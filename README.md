# Rishabh Singh — Personal Site

A simple, static personal website built with plain HTML + CSS.

**Live URL:** `rsingh37.github.io/personal-site` (once deployed)

## What's here

- `index.html` — the page (hero, about, blog placeholder, connect links)
- `style.css` — dark theme, blue accent, responsive

## Tech

- Plain HTML + CSS (no build step, no dependencies)
- Hosted free on **GitHub Pages**

## Editing

Open the project in **px0** to browse and edit:

```bash
px0 /c/Users/Risha/personal-site
```

Then open `http://127.0.0.1:7777` in your browser.

## Deploy

1. Create a repo `personal-site` under `rsingh37` on GitHub
2. Push this code
3. Enable GitHub Pages in repo settings (Source: `main` branch, `/docs` folder or root)
4. Site goes live at `rsingh37.github.io/personal-site`

## Customize

Edit these to make it yours:

- `index.html` — your name, bio, LinkedIn URL, email
- `style.css` — colors in `:root` at the top (bg, accent, font)
- Add a `avatar.png` and reference it in `index.html` if you want a photo

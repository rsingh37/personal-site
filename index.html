About

I'm Rishabh — a backend engineer who enjoys the messy middle of building systems. I write code that talks to databases, queues, and occasionally other code. My work lives between "it works on my machine" and "why is production on fire?"

I care about the stuff that's invisible when it works and impossible to ignore when it doesn't — latency, consistency, retries, the garbage collection of bad decisions. If a system is doing its job, you shouldn't notice it. That's the goal.

7.5+ years building scalable backend and distributed systems — Django services powering multi-integration platforms, Redis caching, Kafka event-driven workflows, and production on AWS EKS. Currently tinkering with agentic AI workflows for backend dev.
